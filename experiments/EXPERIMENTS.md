# 变现实验台账

这里记录"信息源 → 标准化 → 实验 → 钱"的每一次尝试。规矩只有三条：

1. **先写一页备忘录再动手**：假设、成本、止损、分工（代理做什么 / Conny 按步骤点什么），
   放在 `experiments/<实验名>/MEMO.md`。
2. **真金白银记在这张表里**：花了多少、赚了多少，数字过期了就更新。
3. **结论必须写下来**：不管成功失败，实验结束时在备忘录里写"学到了什么、下一步做不做"。
   没写结论的实验等于没做——下次还会在同一个地方犹豫。

账号、密码、银行和税务信息**永远不进 git**，只住在 Conny 自己的设备和密码管理器里。
