# A small handoff that survives switching agents

When delegating, keep one episode directory as the shared record. A design brief identifies the learning objective, source facts, chosen preset, visual changes, asset paths, narration lines and acceptance criteria. The engineer's report lists rendered files, verification, defects and unresolved choices. The reviewing agent checks the actual artifact rather than treating the report as proof.

For this workflow, useful responsibilities are:

- Director: audience, factual claims, topic scope, and final editorial choices.
- Designer: script, storyboard, visual grammar, scene implementation and motion review.
- Engineer: reproducible rendering, speech integration, caption timing, encoding and output checks.

One agent may perform all three roles. A skill does not need three simultaneous paid agents or a particular model brand. Delegate independent work when tools and context make it helpful; avoid concurrent edits to the same scene or simultaneous desktop control.

Use a representative narrated sample to test the hardest style/technical decision early. When the sample reveals a problem, update the design specification before producing hundreds of similar frames. Preserve the final successful decisions in the preset/defaults; leave one-episode experiments in its brief.

For the public reference-method summary and source links, see `docs/REFERENCES.md` in the checkout. Keep observation limits attached to evidence; do not claim that sampled frames establish continuous viewing or listening.
