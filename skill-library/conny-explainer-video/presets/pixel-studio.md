# Pixel studio / 像素工作室

Use for a making-of, agent collaboration story, or workflow tutorial. Inspired by the storytelling device in [路北路陈's making-of](https://www.bilibili.com/video/BV1efHC6METN/). It is distinct from the five design-history topic styles.

## Observed grammar

The reference uses a dark violet studio, a work desk, a large review screen, a render station, timestamp labels and two expressive pixel characters. Dialogue boxes and a director's message strip carry the story. The camera moves between the shared room, a task close-up, and the review screen. At 02:24–02:48 a written brief travels between roles; at 04:06 the accumulated work becomes a production board.

## Original adaptation

Create our own geometric characters and environment. The user/director owns intent and final judgment; design and engineering are assignable roles, not permanent claims about a model's superiority. Show a brief moving to an engineer, an output coming back, and specific review feedback changing the output.

- Canvas: logical 640 × 360, upscale by an integer factor with nearest-neighbor sampling when possible. Render captions as a separate high-resolution overlay for legibility.
- Palette: night `#191629`, wall `#343047`, paper `#EEE8D7`, warm role `#ECA47C`, cool role `#79ACDD`, status `#94BC88`.
- Limit character animation to a few clear poses and modest 2–4 px movement. Keep the room stable so a prop change is meaningful.
- Present short dialogue chunks. Reveal quickly, then hold long enough to read. Do not make bilingual viewers chase a slow typewriter letter by letter.
- Use a review screen to display the actual animation being discussed. A criticism should lead to a visible before/after.
- Alternate room-wide, desk, and review-screen compositions; use purposeful camera travel and restrained pixel dissolves.
- Gentle original synthesized bleeps can mark a handoff or accepted task. Keep narration intelligible; do not reuse the creator's soundtrack.

Our default English narration and Chinese/English captions still apply. The reference making-of is silent dialogue with music; only reproduce that presentation mode when the user asks for a dialogue-only version. Keep characters, speech, captions, and code labels from competing in the same region.

Success means the viewer can identify who decided, who implemented, what was checked, and how the workflow changed. Never imply an external agent ran or approved something unless it actually did.
