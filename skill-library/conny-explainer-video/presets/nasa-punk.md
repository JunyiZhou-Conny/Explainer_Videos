# NASA-punk / Starfield-inspired functional futurism

Use for systems, engineering, exploration, equipment, and procedural explainers. User confirmed this is the intended science-fiction reference, alongside Rhine Lab. Source: 路北路陈's [NASA design episode](https://www.bilibili.com/video/BV1Tsps6kE6z/), especially Starfield at approximately 03:08, the screenshot breakdown at 03:41–04:25, Lone Trail at 04:25, ARC Raiders at 04:57, and the final style card at 05:31. ## Observed grammar

White and light-gray equipment surfaces; panel divisions, visible construction, functional black/white markings, large sans-serif identifiers, small technical labels, retro stripes and patches, one strong accent, and restrained wear. The seven-part closing card separates substrate, structure, hazard graphics, labels, identity, accent, and wear. The Starfield passage builds meaning by identifying these layers within actual equipment imagery. It is more than placing a space photograph behind a title.

## Original production choices

At 1920×1080: shell `#E8E5DC`, inset `#C8C9C4`, ink `#202322`, accent orange-red `#DB4B32`. A muted navy/ochre stripe may identify a subsystem; keep it small enough that the orange-red remains the attention cue. Use Inter for headings and an available readable mono for IDs. Use minimum 30 px meaningful labels, 40–48 px body, 80–120 px primary heading. Reserve the bottom 170 px for Chinese above English captions.

Arrange one functional console or equipment diagram in a 12-column system. Give every seam a reason: module boundary, removable panel, data region, or progress marker. IDs should identify the actual subject (`INPUT 01`, `RENDER QUEUE`, `ASSET BAY`), not random classified-sounding filler. Use original marks; do not reproduce NASA, Starfield, Constellation or game faction logos as the user's identity.

## Motion that explains

- Start with a closed system, reveal labeled modules, then trace one input through them.
- Slide a panel aside to expose an internal process; use 0.5–0.9 s movement and a settled reading hold.
- Light a status lamp only when the corresponding operation changes state.
- Move a technical callout to its real target; enlarge that target before small details matter.
- End with the full assembled system so the viewer can locate the parts they learned.

Use short purposeful camera moves and then stop. A subtle parallax layer or shallow material shadow can establish physical construction. Wear is a sparse material cue, never a filter across body text. Sound, if included, should support a control action and remain below narration.

## Teaching example

Explain a rendering pipeline as an equipment rack: SCRIPT cartridge → VOICE unit → FRAME processor → CAPTION panel → MP4 output. Each connection carries the actual artifact name and changes state when the narration explains it. On errors, show the relevant module and the corrective action.

## Boundaries and acceptance

Avoid neon cityscapes, floating hologram clutter, generic cyberpunk green, decorative warning tape everywhere, fake gauges, and illegible tiny type. Rhine Lab's suspended glass archive is a separate preset; cassette-futurism emphasizes CRTs and tangible analog controls. This preset emphasizes functional aerospace hardware and graphic identification.

Inspect a narrated sample: can viewers follow the data path, identify the active module, read the captions, and distinguish a label from a button?
