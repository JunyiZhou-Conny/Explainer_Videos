## **View Remote Data**

To view a DVC repository, listing data files and directories tracked by DVC alongside the remaining Git repo contents.

[dvc list reference](https://dvc.org/doc/command-reference/list)


Create a fine-grained Person Access Token on Github (this will be used as your github password):
https://github.com/settings/personal-access-tokens

Give access to only the private repo we are working with.

For Permissions, choose Content and it should be Read-only.
