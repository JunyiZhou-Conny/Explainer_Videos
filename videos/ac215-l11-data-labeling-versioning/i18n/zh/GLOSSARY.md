## 为什么要中英混用

- 中国的 MLOps 工程师和助教带实验课时本来就中英混着说：“给这张图打个 label”“Label Studio 里建了 21 个 task”“配一下 source storage”“把 pre-signed URL 打开”“用 gcsfuse 把 bucket 挂上来”“加个 capability”“跑一下 dvc add”“看一下 manifest”“加一个默认 remote”“打个 tag 推上去”“报 401 了”。这些在实验课上本来就用英文说的词，字幕里照说；书面词留给标题、章节名和配套文档（A13）。
- 这是跟练视频：观众要照着敲命令，要在两份英文 README、Google Cloud 控制台、Label Studio 页面、GitHub、终端和 Colab 里找东西。命令、参数、文件名、路径、image / container / 网络的名字、服务账号名、角色名、界面上的按钮和菜单、模板名、奶酪选项、tag 和分支的名字、版本号、状态码一旦翻译，就和屏幕对不上了。所以**实物原样，讲解用中文**。
- 已经有通用中文说法、工程师也这么说的概念一律说中文，用 Google Cloud 中文文档、MDN、Git 中文文档和机器学习文献里的标准译名，方便搜索：标注、数据集、版本、版本管理、指纹、哈希、缓存、指针文件、前缀、对象、数据湖、挂载、挂载点、可用区、跨域、同源、预检请求、响应头、分支、暂存、安全目录、监控、数据漂移、可复现。
- 双语字幕带把英文原句放在每行中文的正下方，所以中文行不加任何括注，也不给保留英文的词加中文解释。
- 这个系列不翻译画面：终端、代码面板、README 卡片、控制台 / Label Studio / GitHub / Colab 的示意图、贯穿全片的地图、签了名的票、保安、指纹架子、绳子、标签、进度条、课件标签和思考题 / 快速预测卡片都保持英文，只翻译旁白。

## 总原则

用一位中国 MLOps 助教在实验课上带同学一步步操作时的普通话，只在这样的人真的会说英文的地方说英文，写成英文旁白下面的字幕。观众已经会说“把 repo clone 下来”“起一个 container”“构建 image”“打 tag”“push 上去”“发布一个 port”“建一个 bucket”“建一个服务账号”“走 ADC”“配 CORS”“看 origin”“报 401”；这一讲再加上“打 label”“做标注”“建一个 task”“配 source storage”“开 pre-signed URL”“挂 gcsfuse”“加 capability”“跑 dvc add”“加一个 remote”“看 manifest”“算 MD5”“打 dataset tag”“做时间旅行”。每个选择过三关：实验课上的真实说法；能搜到的标准中文名（Google Cloud 中文文档：服务账号、凭据、对象、前缀、可用区；MDN：跨域、同源、预检请求、响应头；Git 中文文档：分支、暂存、安全目录；机器学习文献：数据集、标注、数据湖、数据漂移、监控、可复现）；和系列保持一致（第 1 讲定下共用的词，第 2 讲定下容器和缓存的词，第 3 讲定下密钥和 bucket 的词，第 4 讲定下网络的词，第 5 讲定下哈希和疏漏的说法，第 8 讲定下数据集，第 10 讲定下 CORS 和令牌的词：它们定下的写法一律沿用）。

## 关键决定

- **和 BRIEF 提示不同的地方：系列一致性优先**（A1、A3、A4）。BRIEF 的 “Chinese glossary heads-up”（BRIEF.md:919–923）建议 Label Studio、task、annotation、source / target storage、pre-signed URL、CORS、origin、preflight、bucket、prefix、mount、bind mount、FUSE、gcsfuse、DVC、remote、cache、manifest、md5、hash、pointer file、tag、annotated tag、commit、Colab、token、legacy token 都保留英文，标注、版本管理、指纹说中文。其中前几讲已经定成中文的，这里沿用：**前缀**（第 3、10 讲）、**挂载**（第 3、10 讲）、**预检请求**（第 10 讲）、**缓存**（第 2 讲）、**哈希**（第 5 讲）、**访问令牌 / 令牌**（第 3、10 讲：单独的 token 指访问令牌时一律说“令牌”）。另外两处改用中文：annotation 用日常说法**标注**（活动和那条记录都叫标注，和 label 分开，见下一条）；pointer file 用标准译名**指针文件**（DVC 中文资料就这么叫，也不和别的词撞）。其余照 BRIEF：**Label Studio、task、source / target storage、pre-signed URL、CORS、origin、bucket、bind mount、FUSE、gcsfuse、DVC、remote、manifest、MD5、tag、commit、Colab、legacy token** 保留英文。这几处是待 Conny 确认的决定。
- **label 保留英文，标注说中文，标签只给画面标签**（A3、A8）：label 是观众点的那个类别词，也是磁盘上那张 JSON 小纸条（这些 label 就是 ground truth；一条 label 就是一张 JSON 小纸条）；labeling / annotation → 标注（标注站；每条标注一个 JSON 文件；标注几张）。不用“标签”译 label，因为系列里“标签”已经用在画面标签上（your turn 标签、金色标签），书面语里也是 tag 的译名（第 2 讲）。
- **task、manifest、remote 照说**（A1 c）：“任务”会和练习、观众自己的任务混，Label Studio 屏幕上数的也是 task；manifest 译成“清单”会和 S16 的收尾清单撞；remote 单说“远程”在口语里不是名词。书面语里分别写 任务（task）、清单文件（manifest）、远程存储（remote）（A13）。
- **pin 和锁定分开**（A4）：pins / pin down（一行字锁定 600 KB；tag 锁定这份列表；它锁定了这六行）→ 锁定；pin 只留给“pin 住某个版本”，同第 1 讲（由 lock 文件 pin 住；课程 pin 住的那版 README）。
- **两个 origin**（A8）：CORS 的 origin（页面的 origin、任意 origin、另一个 origin）和 git remote 的名字 origin（把你的 repo 加为 origin；remote origin 已经存在）都保留英文，靠后面的中心词区分。
- **报错信息译成中文**（A7）：系列的惯例是短的终端原文照抄（第 10 讲的 Name or service not known）；这一讲的报错都是长句子，旁白用小写转述，所以中文行翻译旁白的转述（找不到文件、它的数据目录不可写、这个组织已经停用了 legacy token 身份验证、包 google-cloud-sdk 没有可安装的候选版本、特殊设备不存在、仓库路径不属于当前用户、remote origin 已经存在、未知的 Git 修订版本），终端和英文行保留原文。照抄的只有旁白点到的状态词和状态码：Up、Exited、401。
- **带下划线的名字**（A6、B3）：这一讲带下划线的实物特别多。cheese_dataset → cheese dataset，cheeses_unlabeled / cheeses_labeled → cheeses unlabeled / cheeses labeled，dvc_store → DVC store，dataset_v20 → dataset v20，Image_1 → Image 1，brie_2 → brie 2，depends_on → depends on 这个设置；英文行用 en_display 给出字面形式（D4）。
- **多加的 capability 不是 extra**（A15、D5）：S10 的 the extra capability 指 --cap-add，译“多加的那个 capability”；“额外”只给画面上标了 extra 的检查和步骤。
- **relay 译“中转”**（A3）：Label Studio 不中转照片；“转发”留给第 10 讲 -p 的端口转发。
- **疏漏一律说“一个小疏漏”**（A10，同第 5、9、10 讲）：S06 README 把原因归到反向 DNS 查询上，S10 没有哪一步说要把第一批照片放进 images，S11 starter 的 Dockerfile 第 36 行（“不是你的错”）。implicit-dirs 和空目录版本是“陷阱”（英文就叫 trap）。
- **S05 的如实说明**（A10）：这台机器没有 Google 账号、没有 bucket、没有浏览器、没有通往 GitHub 的 SSH 通道；目录列表里的密钥是一个明显无效的替身，每个云端步骤之前都会移走；之后每个成功结果都标着 recorded 并注明出处，点击和上传在本地重放，标着 stand-in。说得和英文一样平实，不道歉，也不藏。
- **ours / yours 不能混**（A10、C1）：我们的替身里是 3 个 task，你那边是 21 个；我们的 v21 manifest 和课程的不一样，从不说“应该一致”；只有 v20 和授课老师的 tag 一字不差。
- **画面标签照画面写**（同第 2–10 讲）：黄色的 your turn 标签、灰色的 extra 标签、标着 recorded、标着 stand-in；GOLD 计费标签按颜色说“金色标签”，金额一律说“每月不到一美分”。旁白自己说的照常翻译：额外检查、进度条、地图、替身（A11）。
- **录制时**：at the time of recording 每次都译“录制时”，绝不省略（S04 的 1.23.0 和提示的 1.23.2，S15 的 DVC 3.67.1）；DVC 3.63.0 旁白说的是“由 lock 文件 pin 住”，中文也照这样说，不加“录制时”（A10、C2）。
- **按英文时间轴读**：中文是边听英文边读的，每句中文读起来的时间要和英文听起来差不多；删掉多余的连接词和重复的主语，绝不删内容；长实物（data-service-account.json、docker-shell-compose.sh、API Tokens Settings）英文没重复的地方不要重复（D8）。

## 术语表

“字幕”是中文字幕行里的写法（标题和配套文档用 A13 的书面形式）；“首次出现”给出例句（SNN[k]：场景 SNN 第 k 段 SAY 里一个英文句子对应的一个中文句子，k 从 0 数），翻译 narration 时直接沿用，每一句都能通过检查器。“说明”一栏和 glossary.yaml 的 note 相同（多为英→中的用法对照）。这个系列没有中文配音，所以没有第 1 讲的“朗读（say:）”一栏。
