IN MY OWN WORDS:
(a) 9! = 9×8×7×…×1 counts every order in which the 9 squares could fill up, as if nobody stops after three in a row. A real game that ends early gets counted again for every made-up way of filling its empty squares. A game won on move 5 has 4 empty squares, so it's counted 4×3×2×1 = 24 times. Move 6 games are counted 6 times and move 7 games twice. So 9! is way more than the real number.
(b) A ghost game is a fake ending: moves "played" after someone already won. They never happen in a real game, so they shouldn't be counted. Deleting the winner check brings them all back and gives 9! again.
(c) The program plays every game on one single board, like one whiteboard. It tries a square, counts all the games from there, and then has to erase that mark so the next try starts from the right board. Without the undo line the old marks stay, the board fills up after the first game, and it only counts 3.
(d) The computer knows how every finished game ends: X wins, O wins, or a draw. Going up the tree, on X's turn it picks the child that's best for X, and on O's turn the child that's best for O. Following those picks from the top, you land on a draw. So if both players never make a mistake, nobody wins. (I had to work out the "from the bottom up" part from the colours myself, because the narrator doesn't say it.)
