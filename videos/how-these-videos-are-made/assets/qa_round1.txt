IN MY OWN WORDS:
(a) 9! is too big because it counts every way to fill all 9 squares, as if nobody stops after getting three in a row. A real game that ends early gets counted again for every made-up way to fill the empty squares. A game won on move 5 has 4 empty squares, so it gets counted 4×3×2×1 = 24 times.
(b) A ghost game is one of those made-up endings: the real game plus fake extra moves played after someone already won. It never really happens, so it shouldn't be counted.
(c) The program plays every game on one single board, like one whiteboard. After it tries a square and counts all the games from there, it has to erase that mark (undo) so the next try starts from the right board. Without undo the old marks stay, the board fills up after the first game, and it only counts 3.
