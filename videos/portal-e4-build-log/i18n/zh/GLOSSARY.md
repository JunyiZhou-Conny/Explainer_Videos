# 术语表（项目周记 E4，中文字幕）

旁白是英文，中文字幕只显示、不朗读。规则同 E2–E3：
- 普通话为主；
- 产品名、公司名，以及团队日常说英文的工作用语（agent、review、bot、PR、issue、token）保留英文；
- 数字一律用阿拉伯数字；
- 中文和英文/数字之间加半角空格；
- 字幕句子里不用括号。

| English | 字幕写法 |
| --- | --- |
| pull request | PR |
| draft pull request | 草稿 PR |
| marked ready for review | 标成可以 review |
| review bot | review bot |
| commit / merge / branch | 提交 / 合并 / 分支 |
| handoff note | 交接 |
| decision record · proposed · adopted | 决策记录 · 提议 · 已采纳 |
| session | 会话 |
| the triage brain | 分诊大脑 |
| fact card | 事实卡 |
| rules engine | 规则引擎 |
| checker | 检查器 |
| miss / false alarm | 漏判 / 误报 |
| probe (phrasing) | 探测说法 |
| whack-a-mole | 打地鼠；思考题里用「按下葫芦浮起瓢」 |
| reproduce a bug | 复现 bug |
| usage limit | 用量上限 |
| stop rule | 收尾的约定 |
| urgent care · deductible | 保留英文 |

引用的中文原话（交接、决策记录、`docs/workflow.md`）照原文使用，见 `../../SOURCES.md`。
