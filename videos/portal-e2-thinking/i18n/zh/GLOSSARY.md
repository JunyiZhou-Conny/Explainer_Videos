# 术语表（项目周记 E2，中文字幕）

旁白是英文，中文字幕只显示、不朗读。规则沿用 CareOneX 系列：普通话为主；产品名、公司名、API 名，以及团队日常说英文的
工作用语（token、agent、review、JSON）保留英文；数字一律用阿拉伯数字；中文和英文/数字之间加半角空格；中文标点用全角。
字幕句子里不用括号，需要注释时用逗号或「也就是」。

| English | 字幕写法 |
| --- | --- |
| token | token |
| reasoning model | 推理模型 |
| chain of thought | 思维链，chain of thought |
| reasoning effort | reasoning effort，也就是思考强度 |
| streaming | 流式输出 |
| server-sent events | server-sent events |
| checker | 检查器 |
| receipt | 收据 |
| usage report | usage 报告 |
| cache | 缓存 |
| decision record | 决策记录 |
| proposal | 提议 |
| research preview | 研究预览 |
| replay | 回放 |

产品界面上的中文字符串（「正在思考 · 11 秒」「思考了 22 秒」「思考强度 中」等）照截图原样使用。
