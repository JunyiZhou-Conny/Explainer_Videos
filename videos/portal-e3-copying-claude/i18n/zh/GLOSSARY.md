# 术语表（项目周记 E3，中文字幕）

旁白是英文，中文字幕只显示、不朗读。规则同 E2：普通话为主；产品名、公司名，以及团队日常说英文的工作用语（agent、review、Bugbot）保留英文；
数字一律用阿拉伯数字；中文和英文/数字之间加半角空格；字幕句子里不用括号。

| English | 字幕写法 |
| --- | --- |
| empty state | 空白页 |
| suggestion chips | 建议 |
| composer | 输入框 |
| model menu | 模型菜单 |
| send key / stop key | 发送键 / 停止键 |
| user bubble | 气泡 |
| action row | 操作按钮 |
| disclaimer | 免责声明 |
| decision record | 决策记录 |
| Jakob's law | 雅各布定律 |
| screen reader | 读屏软件 |
| demo replay | 演示回放 |

页面上的中文字符串（「哪里不舒服？」「危及生命直接打 911」「复制给家长」等）照源代码原样使用。
