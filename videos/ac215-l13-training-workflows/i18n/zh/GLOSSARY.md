## 为什么要中英混用

- 中国的 MLOps 工程师和助教带实验课时本来就中英混着说：“把 repo clone 下来”“起一个 container”“构建 image”“建一个 bucket”“开一个 run”“加一个 callback”“config 里”“跑 15 个 epoch”“batch 大小 32”“loss 降下来”“换个 base image”“看 worker pool spec”“做 all-reduce”。硬说“运行”“回调函数”“配置项”“存储桶”，在实验课上反而像说明书；“运行”还会和动词“跑 / 运行”撞车。
- 这是跟练视频：观众要在自己的终端、Colab 和控制台里找到画面上的东西。命令、参数、文件名、路径、包名、image 名、环境变量、角色名、控制台和 Colab 的按钮、W&B 的项目名、报错文字和打印出来的状态行，一旦翻译，就和屏幕对不上了。所以**实物原样，讲解用中文**。
- 已经有通用中文说法、工程师也这么说的概念（实验追踪、可复现、划分、随机种子、训练集、验证集、测试集、微调、冻结、权重、指标、准确率、依赖、模块、无服务器训练、配额、服务账号、服务代理、密钥、角色、软件源、架构、环境变量、策略、副本、梯度、学习率）一律说中文，用 Google Cloud、TensorFlow 中文文档和 ML 文献里能搜到的标准译名。
- 双语字幕带把英文原句放在每行中文的正下方，所以中文行不加任何括注，也不给保留英文的词加中文解释。
- 这个系列不翻译画面：终端、代码面板、notebook 画框和保存下来的输出、README 卡片、控制台和 W&B 示意图、训练地图、账本、徽章、开关面板、标签、进度条和思考题卡片都保持英文，只翻译旁白。

## 总原则

用一位中国 MLOps 助教带实验课、领着大家一步步走两个 notebook 和一个 repo 时的普通话，只在这样的人真的会说英文的地方说英文，写成英文旁白下面的字幕。观众已经会说“把 repo clone 下来”“起一个 container”“构建 image”“建一个 bucket”“建一个服务账号”“跑 15 个 epoch”“开一个 run”“加一个 callback”；这一讲再加上“存一份 notebook 拷贝”“切到 GPU 运行时”“加一个 secret”“靠 run ID 区分”“打 tar 包”“提交一个自定义任务”“申请 GPU 配额”“看 worker pool spec”“换 base image”“做 all-reduce”。每个选择都要过三关：实验课上真的这么说；是能搜到的中文标准译名（Google Cloud 中文文档：服务账号、服务代理、配额、区域、加速器、角色；TensorFlow 中文文档：分布式策略、副本、梯度；ML 文献：实验追踪、可复现、微调、冻结、训练集、验证集、测试集、随机种子、学习率；Debian：软件源、归档）；和系列一致（第 1–11 讲和这一讲的考前版定下的说法一律沿用）。

## 关键决定

- **任务说明里建议保留英文的词，和系列逐个对过**：container、image、bucket、W&B、run、epoch、batch、GPU、Vertex AI 保留英文（系列和考前版本来就这样）。但 **service account → 服务账号**（第 3、10、11 讲）、**tarball → tar 包**、**custom job → 自定义任务**（这一讲的考前版，沿用第 8 讲的“任务”）、**batch size → batch 大小**（第 8 讲、考前版）：系列已经定下中文说法的地方，系列一致优先。wheel 这份脚本里没有。
- **run 保留英文**（考前版 A1 c）：W&B 的 run 是核心名词，“运行”会和动词撞车。名词说 run（一个 run、五个 run、run ID、这个 run 的 config），动词说“跑 / 运行”。书面写“运行（run）”。
- **job → 任务**（考前版、第 8 讲）：Vertex AI 任务、自定义任务、任务的机器、任务规格（job spec）、任务日志。Google Cloud 中文文档用“作业”，配套文档的对照表里注明（H3）。submit → 提交；commit 在字幕里一直说英文，不冲突（A8）。
- **服务账号 ≠ 服务代理**（A14）：提交任务的是你的 model-trainer 服务账号（密钥文件在你笔记本上）；运行任务的是你项目的 Vertex AI 服务代理（“由 Google 管理的服务账号”，Google Cloud 中文文档的译名）。S11 的徽章比喻：徽章、挂绳、另一栋楼。
- **密钥和 API key**（A8）：key → 密钥（服务账号的 JSON 密钥、W&B 密钥，沿用第 6 讲的“OpenAI 密钥”）；W&B 页面自己的说法 API key 只在 S04 出现一次，保留英文（第 1 讲）；存它的 Colab secret 保留 secret（面板叫 Secrets）；secrets 目录、Secret Manager 照写。
- **配额**（第 5 讲）：GPU quota → GPU 配额，an allowance per region → 每个区域的额度。
- **mirror 分开**：Debian 的 mirror → 软件源（第 1 讲：“镜像”只指 image 的书面说法），security mirror → 安全更新源，archive → 归档源；MirroredStrategy 的 mirrored → 复制（考前版），类名照写。
- **cockpit → 驾驶舱**：课上叫 Model Trainer CLI Container（第一次照写课上的名字），视频里叫 cockpit，就是本地的 model-training-cli container；“驾驶舱”不会和控制台（console）撞车。
- **报错照屏幕原文**（A7）：旁白引用的报错都是屏幕上那一行里连续的一小段，所以中文行照抄：404 Not Found、no installation candidate、api key not configured（A6）、API key must be 40 characters long, yours was 2；打印的状态行照代码的大小写：Training Job Complete、GPU Available。旁白自己转述的才翻译：no active account → 没有激活的账号（屏幕原文是 You do not currently have an active account selected；“激活的账号”和“活跃的 run”分开）。这一点和第 11 讲不同：第 11 讲翻译的是比屏幕原文更长的小写转述。
- **带下划线的名字按旁白念法**（A6）：validation percent、test percent、2 block、train base、model dir 参数、batch 大小参数、密钥参数、region 变量、api key not configured、x86 64、init 文件、find packages、strategy.scope。英文行用 en_display 还原字面形式（D4）。
- **label 保留英文**（第 11 讲）：四个奶酪 label、打印 label 的那一行、label 映射；“标签”只留给画面上的标签（黄色标签、金色标签），setup.py 那个“label”比喻用“铭牌”，activated 那句的“a label, not a fact”说“只是一句话，不是事实”。
- **拷贝 ≠ 副本**（A8）：save a copy / two Colab copies / a copy of the files / an identical copy of the model → 另存一份 / 两份拷贝 / 一份拷贝 / 一份模型拷贝；副本只指 tf.distribute 的 replica 和 worker pool spec 里的副本数。
- **思考题只问不答**（A10），答案在下一段，按英文的顺序先给答案。
- **按英文时间轴读，保持英文的分句顺序**（D8、D9）。
