# 术语表（项目周记 E5，中文字幕）

旁白是英文，中文字幕只显示、不朗读。规则同 E2–E4：
- 普通话为主；
- 产品名、公司名，以及团队日常说英文的工作用语保留英文：agent、reducer、PR、skill；
- 数字一律用阿拉伯数字；
- 中文和英文/数字之间加半角空格；
- 字幕句子里不用括号；TLA+ 写成 TLA plus，因为检查器不允许字幕里出现「+」。

| English | 字幕写法 |
| --- | --- |
| reducer | reducer |
| state · action | 状态 · 操作 |
| rule | 规则 |
| exhaustive check | 穷举检查 |
| shortest story (counterexample) | 最短复现 |
| known finding | 已知发现 |
| mutation testing | 变异测试 |
| accessible name · screen reader | 无障碍名称 · 读屏软件 |
| evidence | 证据 |

引用的中文原话（规则名、「最短复现」、「已知发现（未修）」、页面文字）照仓库原文使用，见 `../../SOURCES.md`。
