Click squares to play. After every move, the counter shows how many different games can still happen from this board, the same number the program explore() would return. Use Undo to step back, just like the program does.

Try this

  1. Before any move the counter says 255,168. Put X in the centre. How many games are left now? Then undo and try a corner and an edge. Which first move leaves the most games?
  2. Find a board where the counter says exactly 1. What kind of board is that?
  3. Play X in square 0, O in 4, X in 8. Who wins most of the remaining games?
  4. Find a board, with empty squares left, where every remaining game is a draw.
  5. Find the board with the most games that end on move 5. (Hint: it takes four moves to get there.)
