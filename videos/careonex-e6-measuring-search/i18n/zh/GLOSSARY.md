# 术语表（CareOneX 系列，中文字幕）

字幕给中文母语的 CS 研究生看：普通话为主；代码名、容器名、AWS 产品名，以及团队日常说英文的工作用语
（pipeline、chunk、embedding、hash、sidecar、bucket、agent）保留英文，第一次出现时在（…）里注一次中文。
数字一律用阿拉伯数字；中文和英文/数字之间加半角空格；中文标点用全角。

| English | 字幕写法 |
| --- | --- |
| container | 容器（container） |
| source list | 来源清单（source list） |
| hash | hash（哈希值） |
| S3 bucket | S3 bucket（存储桶） |
| sidecar | sidecar（元数据文件） |
| manifest | manifest（清单） |
| chunk | chunk（文本块） |
| vector | 向量 |
| cosine similarity | 余弦相似度（cosine similarity） |
| Knowledge Base | Bedrock Knowledge Base（知识库） |
| ingestion job | 导入任务（ingestion job） |
