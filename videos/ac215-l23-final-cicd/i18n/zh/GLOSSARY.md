## 为什么要中英混用

- 中国的 MLOps 工程师和助教带实验课时本来就中英混着说：“push 到 ECR”“跑一下 playbook”“这个 play 里有几个 task”“看 recap 里 failed 是不是 0”“报 UNREACHABLE 了”“挂 Docker socket”“用 extra vars 传进去”“这个 job 被跳过了”“在 runner 上跑”“加一个 secret”。这些在实验课上本来就用英文说的词，字幕里照说；书面词留给标题、章节名和配套文档（A7）。
- 这是跟练视频：观众要照着敲命令，要在英文 README、终端、AWS 控制台、GitHub 页面和代码面板里找东西。命令、参数、文件名和路径、关键词和 commit 信息、策略名和用户名、控制台标签、工作流的步骤名、recap 的计数、报错原文一旦翻译，就和屏幕对不上了。所以**实物原样，讲解用中文**。
- 已经有通用中文说法、工程师也这么说的概念一律说中文，用 AWS 中文控制台和文档、Ansible 中文文档、中文 CI/CD 资料里的标准译名，方便搜索：IAM 用户、策略、AWS 托管策略、访问密钥、私有访问密钥、密钥对、安全组、实例、系统映像、区域、公有 IP 地址、终止、停用、附加、模块、声明式、持续集成、持续交付、持续部署、发布、工作流、步骤、滚动更新、数据漂移。
- 双语字幕带把英文原句放在每行中文的正下方，所以中文行不加任何括注，也不给保留英文的词加中文解释。
- 这个系列不翻译画面：终端、代码面板、README 卡片、进度条、各种标签、控制台和 GitHub 的示意图、V1–V8 的示意图、recap 方块、思考题和自测卡片都保持英文，只翻译旁白。

## 总原则

用一位中国 MLOps 助教在实验课上带同学一步步部署时的普通话，只在这样的人真的会说英文的地方说英文，写成英文旁白下面的字幕。每个选择都过三道关：实验课上真的这么说；是 AWS 中文控制台和文档、Ansible 中文文档、中文 CI/CD 资料里能搜到的标准译名；和本系列一致（第 1–22 讲定下的写法一律保留，尤其是 AWS 先例第 15 讲、部署工具箱的第 20 讲和 GitHub Actions 的第 21 讲）。

1. **实物原样**：观众要输入、要在屏幕上对照的东西（命令、参数、文件名和目录名、路径、关键词和 commit 信息、image / 网络 / 用户的名字、控制台标签、工作流的步骤名、recap 的计数、旁白引用的报错原文）逐字照抄，不翻译、不变形、不加引号。检查器逼出来的例外（字母之间的下划线、= > 或括号）按旁白的说法写（A9），英文行显示原样（D4）。画面上的一切都是英文，只翻译旁白。
2. **实验课口语里的英文，封闭清单**：系列已有的 repo、clone、commit、push、pull、origin、main、container、image、tag、Dockerfile、port、localhost、registry、bucket、pipeline、shell、root、socket、pin、prune、collection、agent、job、runner、secret、action、run、playbook、provision、ID、IP、API、JSON、YAML、URL、CSV、SSH、HTTPS、CI、CD、Ingress、Pod；**这一讲新增 play、task、inventory、hosts、recap、register、extra vars、here string、volume**。
3. **其余用中文标准术语**（A2–A6、A10–A12）。
4. **视频里的图按意思译，一个图一个词，每次都一样**（script.md 的比喻表）：筛子（sieve）、徽章（badge，访问密钥）、钥匙（密钥对的钥匙图标）、工具箱容器（toolbox）、前门（front door，nginx）、发布按钮（release button）、保险库（GitHub 上的 vault）、总图（课上的 map）、替身（stand-in，同第 10、20 讲）、一环（&& 链里的一段）。
5. **标题、meta.yaml 和配套文档用书面语体**：容器、镜像、仓库、端口、镜像仓库（registry）、提交、提交信息、推送、机密（secret）、流水线、工作流、置备（provisioning）。
6. 双语字幕带把英文原句放在每行中文下方，所以中文行不加任何括注（检查器在没有 say: 时也不允许括号）。
7. 工具链的约束也是原则的一部分：一个英文句子对一个中文句子（136 段、360 句）、显示行能通过检查器（D3）、SAY 把实物念成单词的地方一律加 en_display（D4）、保持英文的分句顺序（D9）。大陆简体中文；轻松、清楚的实验课口语，不油滑。

## 关键决定

- **跟 AWS 版走，温和地对照课件的名词**（A12、A16）：课件讲 Google Cloud（GKE、GCR、Pulumi、服务账号密钥、Ingress、/deploy-app），本片跟 cheese-app-aws。字幕说“课件讲的是 Google Cloud；我们跟的是 AWS 的 repo”，然后逐个对照：Kubernetes 集群 → 一台 EC2 服务器，registry → ECR，Pulumi → Ansible 的 playbook，服务账号密钥 → 两份密钥，关键词 → /run-deploy-app，Ingress → 前门的 nginx。绝不说课件错了。
- **Ansible 的结构词保持英文，module 说“模块”**（A5）：playbook（第 20 讲已定）、play、task、inventory、hosts、recap、register、extra vars 是中文 Ansible 使用者在实验课上照说的词，屏幕上也都是这些英文；Ansible 中文文档的“剧本”“任务”“清单”在实验课上几乎没人说，task 说“任务”还会和一般意义的任务混。“模块”是通用说法，照译。
- **toolbox 一律是“工具箱容器”**（A2、policy 4）：script.md 的比喻表把 toolbox 定为“工具箱容器”，每次都一样；第 20 讲写的是“工具箱”，这一讲按 script 的要求用较长的形式，强调它是一个 container（S06 的思考题正是问 image 落在它里面还是旁边）。
- **两份密钥、secret、/secrets、NextAuth secret 分开**（A3、A10）：笔记本上的访问密钥和密钥对合称“两份密钥”；GitHub 的仓库 secret 照第 21 讲说 secret；/secrets 是目录；secret access key 是 AWS 中文名“私有访问密钥”；NEXTAUTH_SECRET 写成 NextAuth secret。比喻图里的 badge 是“徽章”，key 图标是“钥匙”，真正的密钥才叫“密钥”。
- **镜像只指 container image**（A10，第 1 讲 A6）：AMI（machine image）用 AWS 中文名“系统映像”，不和“镜像”混。ECR 的 repository 是“仓库”（第 15 讲），Git 的 repository 是 repo。
- **EC2 的动词用 AWS 中文控制台的词**（A4）：terminate → 终止（≠ 停止、删除），attach 一块磁盘 → 附加（≠ 挂载 mount；≠ 第 15 讲给策略用的“挂上”），deactivate → 停用，public IP address → 公有 IP 地址，security group → 安全组。EBS 的 volume 照系列说 volume。
- **持续交付和持续部署分开**（A6）：课上把 continuous delivery（有人按发布按钮）和 continuous deployment（每个通过的改动自动上线）并列，S14 的思考题就问 /run-deploy-app 算哪一个。delivery 一律是“持续交付”，release 是“发布”（同第 21 讲），release button 是“发布按钮”。
- **检查器不收的实物按旁白的说法写**（A9、B3）：ci_cd_aws.yml → ci cd aws.yml，head_commit → head commit，cluster_state=absent → cluster state 设为 absent，DOCKER_TAG → Docker tag 变量，AWS_SSH_KEY → AWS SSH key，NEXTAUTH_SECRET → NextAuth secret，EXTERNAL_IP → external IP，group_id → group ID，failed=0 → failed 为 0，ansible>=9.0.0 说成“大于号”“等号”，here-string (<<<) → here string；英文行用 en_display 给出原样（D4）。ac215_2024 和 ac215_2024.pem 检查器收，照写。
- **引用的终端原文照抄，转述的照译**（A15）：credentials file not found、redirection unexpected、Gathering Facts、AWS was not able to validate the provided access credentials、UNREACHABLE、Could not resolve hostname external IP、no attribute group ID、skipping、状态码 410 Gone 照抄；旁白转述的“the security token is invalid”译成“安全令牌无效”，“docker login received an empty password”译成“docker login 收到的是一个空密码”。
- **勘误和说明，固定说法**（A12、D6）：A small slip → 有一个小疏漏（S08 换密钥）；A small gap → 一个小出入（S03 密钥对名字）；A kind note → 说明一点（S08 的 GCP 标题）；如实说明录制环境的那句（S01[4]）只说一次，不道歉，后面每个第一个报错都只是下一句；没测试过的照英文保留不确定。
- **思考题不泄底**（A12）：五道思考题（S06[1]、S10[2]、S12[3]、S14[9]、S15[0]）只问不提示；A question. → 想一想。，Predict: → 预测一下：，Your turn. → 轮到你了。；揭晓时用题目自己的话回答（你笔记本的。/ /newsletters。/ 只构建和 push。/ 持续交付。）。
- **“your turn”和“录制时”**（A12、A13、D6）：屏幕标签 your turn 照抄，旁白里的 pause and run it → 暂停一下，自己跑一遍；at the time of recording → 录制时（版本号只在屏幕上）；Ours … ; yours … → 我们的……；在你的……。
