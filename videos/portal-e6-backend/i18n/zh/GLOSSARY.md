# 术语表（项目周记 E6，中文字幕）

旁白是英文，中文字幕只显示、不朗读。规则同 E2–E5：
- 普通话为主；
- 产品名、公司名，以及团队日常说英文的工作用语保留英文：agent、PR、issue、bot；
- 数字一律用阿拉伯数字；
- 中文和英文/数字之间加半角空格；
- 字幕句子里不用括号。

| English | 字幕写法 |
| --- | --- |
| backend · server · database | 后端 · 服务器 · 数据库 |
| login · one-time code · hash | 登录 · 邮箱验证码 · 哈希 |
| container | 容器 |
| decision record · proposal · adopted | 决策记录 · 提议 · 已采纳 |
| family link · invite code | 家庭关联 · 邀请码 |
| migration | 迁移文件 |

决策记录里的中文原话照原文使用，见 `../../SOURCES.md`。
