# Sources and privacy of the example

This video describes an owner-authorized inspection of one Mac on 2026-10-12. It is a dated
case study, not a promise that another computer has the same layout or folder counts.

The local audit found 83 user skill folders under `~/.agents/skills`, 25 managed folders under
`~/.cursor/skills-cursor`, and no personal `~/.cursor/skills` folder at the pre-install baseline.
It compared file contents to distinguish provenance evidence from an unknown installation
actor. In particular, matching skill contents establish that files match; they do not identify
who clicked an install button. The complete inventory, configuration contents and private
project filenames stay on the owner's machine and are not required to render this example.

Public documentation used for the conceptual explanation:

- [Agent Skills format](https://agentskills.io/specification)
- [Codex skills](https://learn.chatgpt.com/docs/build-skills)
- [Cursor skills](https://cursor.com/docs/skills)
- [Claude Code skills](https://code.claude.com/docs/en/skills)

The seven visual presets mentioned in the narration were the catalog at recording time.
The incubator now also indexes its pre-existing `3b1b` family. That later addition does not
change the historical narration. See the individual preset files for visual-reference
attribution and observation limits. No third-party reference footage is embedded here.
